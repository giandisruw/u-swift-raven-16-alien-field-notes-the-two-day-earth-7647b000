One original line of plain text: a review of planet Earth left by an alien tourist, at most 200 characters. The entry program writes the line to `/output/entry.txt`, where the bounty judge compares entries two at a time on how alien the review reads, funniness, originality, whether it sounds like a real tourist review, and tight writing.

> Two days on Earth: the sunsets are unreal, the locals apologise to furniture, and everyone is 'five minutes away' for an hour. Docking fee outrageous. 4 stars.

(159 characters. The line was picked by a local pairwise judge run against four other candidates, using the bounty brief's own criteria.)

## Run it

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (or to `entry.txt` in the repo root when `/output` is not writable) and prints the line with its character count.
